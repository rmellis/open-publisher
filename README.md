## Overview

Open Publisher is a WYSIWYG (What You See Is What You Get) desktop publishing application built as a free alternative to tools like Microsoft Publisher. Whether you are creating newsletters, flyers, business cards, posters, booklets, or marketing materials - Open Publisher gives you precision layout tools, rich typography, image manipulation, and comprehensive export capabilities, entirely free.

## What's New in Version 5

Version 5 is the most significant release in Open Publisher's history - a complete re-engineering of the desktop wrapper, canvas engine, and print pipeline. Every area of the application has been rebuilt or substantially improved.

<details>
<summary>🔍 Expand to see all V5 feature highlights</summary>

### 🛡️ Saving, Backups and File Safety

- **Atomic Save Pipeline** - Every save uses a 4-step crash-safe write: write to `.tmp`, verify byte length, rotate existing file to backup, atomically rename. If anything fails, the original is never touched - corruption is physically impossible.
- **Auto-Save on Idle** - Automatically saves named documents silently after 10 minutes of system inactivity using Chromium's idle detection API. No user action required.
- **Idle Save Modal** - For unsaved new documents, a single draggable in-app dialog appears after 10 minutes of inactivity prompting Save As. Never stacks duplicate dialogs no matter how long you're away.
- **Backup Manager** - A draggable, searchable modal listing all `.bak` backup files with publication name, date/time, file size, and page count. Open any backup as a safe independent copy; saving it triggers Save As rather than overwriting the archive.
- **Backup Directory Relocation** - Backup files are now stored in `AppData\Local\OpenPublisher\Backups` instead of your working project folder. Old `.bak` files in working directories are cleaned up automatically on the next save.
- **Previous Versions** - Automatic timestamped snapshots every 15 minutes for documents with unsaved edits, plus a snapshot before every manual save. Up to 50 snapshots per document. Includes search, filter by current document, manual "Take Snapshot", "Open as Copy", and "Restore" with safety backup.
- **External File Watcher** - Monitors the open `.opub` file for external changes (cloud sync, other editors). Detects modifications and prompts you to reload. Intelligently ignores events from the app's own save process.
- **Non-Blocking Async Save** - Saving large documents never freezes or stutters the UI. The entire save pipeline runs on a background IPC stream.
- **Power Management Keep-Awake** - The OS is prevented from sleeping or activating the screen saver during saves and exports. Normal power behavior resumes immediately afterward.
- **Native Desktop Save Notification** - A native OS notification toast appears after every successful save.

### 📋 Clipboard and Copy/Paste

- **Canvas Element Copy, Cut and Paste** - Fully functional copy, cut, and paste of canvas elements via `Ctrl+C/X/V`, ribbon buttons, right-click menu, and the native menu bar. Correctly distinguishes between copying a canvas element vs. copying text inside an active text box.
- **Clean Native Clipboard Paste** - The Paste button in the ribbon and right-click menu silently invokes the native OS clipboard paste, bypassing web security restrictions. Preserves all rich clipboard data including fonts, RTF, and images.
- **Clipboard Bug Fixes** - Fixed double-pasting, ribbon Paste button ignoring newly copied external content, internal canvas tokens leaking as raw text into text boxes, and copy failing in sandboxed environments.
- **Clipboard Scrapbook** - A persistent floating sidebar drawer that monitors the OS clipboard for images every 2 seconds and caches the last 25. Insert any image onto the canvas with one click or drag-and-drop. Persists across application launches.
- **Paste Image Separation** - When pasting mixed content from a website, images are automatically separated from text. Text pastes into the text box; images are independently placed on the canvas as separate objects.

### 📁 Drag and Drop

- **Drag-and-Drop Publication Opening** - Drag any `.opub` or `.json` file from Windows Explorer onto the app window to open it. A full-screen "Drop to open publication" overlay appears during the drag.
- **Document Pour Animation** - When any document opens, canvas elements animate into place from top to bottom with a smooth organic stagger and a teal-green wave sheen. Eliminates the old flash-of-content glitch.
- **Image Drag-and-Drop Import** - Drag image files (PNG, JPEG, GIF, WebP, SVG, BMP, ICO, AVIF, TIFF) from any folder directly onto the app window to import them onto the canvas. The publication-open overlay is suppressed for image drags.

### 🖥️ Window and Titlebar

- **Rounded Corners and Drop Shadow** - The frameless window has a 12px border radius and ambient drop shadow via Windows DWM alpha compositing.
- **Ghost-Frame Resize Engine** - A transparent preview overlay shows exact new dimensions and a live size badge while dragging any edge or corner. Eliminates all resize flicker and lag.
- **Window State Persistence** - Size, position, and maximized state saved and restored exactly across restarts. If the saved monitor is disconnected, the window reappears safely on the primary display.
- **Always-on-Top Pin Button** - Pushpin icon in the titlebar. Glows green when engaged. Tooltip updates between "Pin window" and "Unpin window". Auto-hides on narrow windows.
- **F11 Fullscreen** - Native borderless fullscreen toggle. Titlebar controls stay accessible as an overlay.
- **Dirty-State Asterisk (*)** - Appears next to the document title in the titlebar whenever unsaved changes exist. Disappears immediately on save.
- **Smart Exit Dialog** - The close button only shows an unsaved-changes warning if edits actually exist. Clean documents close instantly with no prompt.
- **Modernized Exit Dialog** - Left-aligned text, pill-shaped buttons, OS-standard 6px corners. Save as primary; "Don't Save" and "Cancel" as outlined secondary buttons.
- **Show in File Explorer** - Folder icon button in the titlebar highlights the current file in Windows Explorer instantly. Dims when no file has been saved yet.
- **Close to System Tray Toggle** - When enabled, clicking X hides the app to the tray instead of closing. Re-launching restores and focuses the existing instance.
- **Single Instance Enforcement** - Opening a second `.opub` from Windows Explorer loads it in the existing window rather than opening a duplicate.

### 🗂️ System Tray

- **System Tray Integration** - Full right-click jump list: Show/Hide Window, New Publication, Open Publication, Save, Recent Publications submenu (synced live with in-app list, with Clear History), Backup Manager, Previous Versions, Developer HUD toggle, and Exit with unsaved-changes guard.
- **Global OS Keyboard Shortcut** - `Ctrl+Shift+O` / `Ctrl+Shift+P` (or `Cmd+Shift+O/P` on macOS) brings Open Publisher to the foreground from anywhere on the OS, even if minimized or hidden in the tray.

### 📊 Taskbar Integration

- **Taskbar Progress Bar** - The taskbar icon shows a live progress bar during saves (indeterminate) and exports (real percentage fill).
- **Taskbar Attention Flash** - When a save or export completes while the app is minimized or in the background, the taskbar button flashes to notify you. Stops automatically when you switch back.
- **Export Priority Elevation** - During active exports, the OS process priority is elevated to above-normal for maximum CPU allocation, then returned to normal on completion.

### 📤 Export and Print Queue Monitor

- **Export and Print Queue Window** - A standalone floating dark-glass window showing real-time progress for all active PDF, image, and print jobs. Includes job history, percentage progress, status indicators, filter by type (All/Print/PDF/Image), "Open in Folder", and direct file launch.
- **Real-Time Export Progress on Taskbar** - Live export percentage from the webapp is reflected on the OS taskbar progress bar (0-100%).

### 📂 Recent Files

- **Recent Files Dropdown** - Titlebar button lists the last 10 opened documents with filename and full path. Clicking an entry fully restores the document's DPI, format, unit, orientation, margins, and spread mode.
- **Single Instance File Association** - Double-clicking a `.opub` from Windows Explorer while the app is open loads it in the existing instance rather than spawning a new window.

### 🎬 Presentation Preview

- **Presentation Preview Window** - A standalone floating frameless window that mirrors the active canvas in real time using pure DOM/SVG cloning (no html2canvas - crisp vector output). Has its own page thumbnail strip, zoom presets (50% to 200%), mouse-wheel zoom, and a dedicated fullscreen presentation mode. Independently moveable; closes with the main app.

### 🚀 Startup and Splash Screen

- **Unified V5 Splash Screen** - Single-phase splash replacing the old double-splash. Features a faceted geometric backdrop, V5 vector branding, real-time boot console with 178 color-coded milestones, and a smooth subpixel progress bar that never goes backwards.
- **Adaptive Dual-Theme Splash** - Teal/green gradient with white logo in light mode; deep dark slate with cyan accents in dark mode. Dynamic status labels update throughout loading.
- **Dynamic OS Edition Detection** - The splash footer automatically displays the correct platform: Windows Edition, Mac Edition, Linux Edition, or FreeBSD Edition - each with its own illuminated platform icon.
- **First-Run Wizard** - An 8-step interactive onboarding tour on first launch. Glassmorphic card design, clickable pill step navigation, Arrow key and Escape support, and a confetti burst on completion. Re-triggerable from the Developer HUD at any time.

### 🎨 Theming and Appearance

- **Theme Persistence Fix** - Theme selections now correctly persist across restarts without resetting to default teal.
- **Window Controls Color Auto-Heal** - Titlebar button icons always render in the correct color for the active theme. Stale incorrect colors from previous sessions are automatically corrected on startup.
- **Custom Dark Scrollbars** - Export Queue and Presentation Preview windows have custom dark navy track / teal thumb scrollbars matching the dark window aesthetic.
- **Subpixel Font Rendering** - Subpixel antialiasing and hardware-accelerated GPU rasterization across all UI text and vector icons.
- **Smooth Image Interpolation** - Scaled icons and images in the ribbon appear smooth and anti-aliased rather than pixelated.

### 🔤 Text Editing and Typography

- **Native Spellcheck** - Bundled offline Hunspell dictionaries for English US (en-US) and English GB (en-GB). Real-time red squiggly underlines. Right-click any misspelled word for correction suggestions.
- **System Fonts Integration** - All locally installed Windows fonts discovered from the registry and merged with Google Fonts into one alphabetically sorted dropdown. Local fonts show a monitor icon; Google Fonts show a "G" icon. Opens in under 20ms using lazy rendering.
- **Horizontal Scrolling and Full Pasteboard** - Hold Shift and scroll the mouse wheel to scroll the canvas horizontally. Full pasteboard margins on both sides so the page can be scrolled completely off-screen at any zoom level.

### 🤖 Clippy Assistant

- **Clippy (Microsoft Agent)** - Summoned from File ribbon Help group, `Alt+H`, or right-click canvas. Features 41 mapped animations, cursor gaze tracking, 101 Open Publisher-specific tips with 20-second auto-dismiss, idle behaviors after 3 minutes, right-click context menu (size scaling 1x/1.5x/2x, CRT filter, silence tips, mute sound), and full preference persistence. Assets fetched on-demand from CDN; offline fallback modal if unreachable.

### 🔧 Developer HUD and Diagnostics

- **Developer Mode HUD** - `Ctrl+Shift+D` opens a floating HUD with real-time RAM, FPS, and DOM node metrics plus Quick Action buttons for Reload, DevTools, First-Run Wizard, Backup Manager, Previous Versions, Safe Mode, and Crash Renderer.
- **Tearaway HUD Window** - The Developer HUD can be popped out into an independent floating window on any monitor. Dock button re-attaches it. Live metrics update in both states simultaneously.
- **Live Memory Chart** - Rolling bar chart of Webview RAM usage with dynamic min/max auto-zoom and a live rate-of-change display (+KB/s, -KB/s, or Steady).
- **IPC Traffic Sniffer** - Toggleable real-time log of all bidirectional IPC messages between the wrapper and webapp, with color-coded [IN] and [OUT] badges and timestamps.
- **Crash Recovery** - Renderer crashes are automatically intercepted. A fresh instance launches with a branded recovery dialog ("Well, This Is Awkward...") offering Attempt Recovery, Let It Burn, or Pretend This Didn't Happen. A full diagnostic crash log is written to the Desktop and a native Windows notification appears.
- **Safe Mode** - Clears Chromium cache and all localStorage on reboot. A red [SAFE MODE] badge appears in the titlebar. Triggerable from the HUD or the `--safe-mode` launch flag.
- **Open AppData Button** - One-click access to the application's hidden data directory in Windows Explorer.
- **Memory Limits Uncapped** - V8 JavaScript heap raised to 8GB. GPU renderer allocated up to 4GB VRAM. Ceilings only - no pre-allocation.

### 🌐 Platform Support

- **FreeBSD Native Port** - Full Electron build with `.opub` file association, XDG icon hierarchy, desktop launcher, and global `openpublisher` CLI command. Standalone `.pkg` installer with zero external dependencies.
- **Universal Linux Flatpak** - Works on SteamOS, Fedora Silverblue, ChromeOS, and any Flatpak-enabled distribution.
- **Linux `.run` Self-Extracting Installer** - Installs on any Linux distribution without requiring a package manager.
- **Linux `.deb` Package** - Native package for Debian, Ubuntu, and derivatives.
- **Linux `.rpm` Package** - Native package for Fedora, RHEL, openSUSE, and derivatives.
- **Linux Bundled Noto Color Emoji Font** - COLRv1 emoji font bundled for Linux systems without a system emoji font. Scoped to emoji codepoints only; all text rendering uses system fonts.

### 🪟 Windows Integration

- **MyDockFinder Native Menu Bar** - Open Publisher integrates with MyDockFinder (a Windows application that provides a macOS-style global menu bar on Windows). Full native menu bar support via a custom 64-bit hook DLL (`op_menu_hook.dll`) that intercepts Win32 window messages Chromium would otherwise ignore. Standard File, Edit, Insert, and View menu commands work from the global MyDockFinder menu bar.

### 🖼️ Bulk Image Import

- **Unified Bulk Image Import** - Select or drag-drop multiple images at once. A modal prompts whether to place all images on the current page in a staggered cascade or create a dedicated new page per image automatically. Single images bypass the modal. Sequential async pipeline ensures strict creation order on large batches.

### 📐 Physical Measurement Units and DPI

- **Physical Measurement Units** - Design using Centimeters (cm), Millimeters (mm), Inches (in), or Pixels. Canvas rulers, dialogs, and coordinate displays all speak your chosen unit.
- **DPI Resolution Control** - Choose from 96 DPI (Screen), 72 DPI (Draft), 140 DPI, 150 DPI, 300 DPI (Print), or a custom value. Page pixel dimensions update in real time.
- **New Document Dialog Overhaul** - Quick format preset buttons (A4, Letter, A3, A5, Legal, Tabloid, Business Card, Square), orientation toggle, units selector, DPI picker, and a live pixel preview banner.
- **Resize Document Dialog Overhaul** - Format presets, live unit conversion, DPI selector, and real-time dimension preview.
- **Custom Margins Dialog** - Enter margins in any physical unit; values convert dynamically.
- **Zero-Spillage 300 DPI Print Engine** - A 300 DPI A4 document (2480x3508px) prints on exactly one sheet with no blank trailing pages or multi-sheet slicing.
- **DPI-Aware Format Detection** - The page format badge (A4, Letter, etc.) correctly identifies formats at any DPI without reverting to "Custom".
- **Format and DPI Saved in .opub** - Page format and DPI are stored as document metadata so documents always reload with the exact paper size and resolution they were saved with.
- **Spread Mode Saved in .opub** - Two-page spread mode is stored per-document. Documents saved with spreads open with spreads; documents saved without do not. Eliminates high-DPI documents incorrectly activating spreads on load.

## Installation and Platform Support

### Windows

Open Publisher ships in two primary distribution formats for Windows:

- **Standard Installer (`.exe`)** - Full installer with Start Menu and Desktop shortcuts, multi-resolution 10-frame high-DPI icon embedding (up to 256x256), and `.opub` registry file association.
- **Portable Version (`.exe`)** - Self-contained zero-install executable. Ideal for USB drives, restricted workstations, or running without administrator rights.
- **Safe Mode Startup** - Launch with `--safe-mode` or `--reset` from the command line to purge cached data, reset layout bounds, and troubleshoot faulty extensions.
- MyDockFinder native menu bar integration support.

### macOS

Open Publisher provides first-class native integration on macOS (Intel):

- Native macOS menu bar with commands categorized across tabs (File, Home, Insert, Page Design, Review, View, Picture).
- Dynamic accelerator keys that automatically adapt to `Cmd` instead of `Ctrl`.
- Authentic process identity ("Open Publisher") across the menu bar, Dock, and system task monitors.
- Native unsaved-changes confirmation dialogs, high-DPI Retina canvas scaling, and zero-flicker boot sequencing.

<a id="data-integrity-saving-and-recovery-systems"></a>
## Data Integrity, Saving and Recovery Systems

Open Publisher V5 incorporates enterprise-grade protections to ensure your creative work is never lost:

- **4-Step Atomic Save Pipeline**:
  1. Writes serialized document data to an isolated temporary file (`[filename].opub.tmp`).
  2. Verifies the written file on disk to guarantee complete, non-zero byte length.
  3. Safely rotates the existing saved document into the backup directory (`[filename].opub.bak`).
  4. Atomically renames the temporary file into place via OS-level `fs.renameSync`.
- **15-Minute Background Snapshots (Previous Versions)**:
  - Operates automatically in the background, capturing rolling snapshots every 15 minutes when unsaved modifications exist.
  - Only activates for named (saved) files - unsaved drafts are skipped.
  - Maintains a 50-snapshot FIFO history per document.
  - Open snapshots via the Previous Versions button in the titlebar to inspect, restore, or open as a fresh copy.
  - **On-Demand Snapshots**: Click "Take Snapshot" inside the dialog to capture a version instantly at any time.
  - **Scope Filter**: Toggle between viewing versions for only the active document or across all projects.
- **Backup Manager**:
  - Draggable modal dialog accessible from the titlebar, Developer HUD, and system tray.
  - Chronological listing of all `.bak` files with publication name, date, file size, and page count.
  - Open any backup directly as a working copy (decoupled from the original file path, so Ctrl+S triggers Save As).
  - Real-time search filter and direct folder access for manual archive management.
- **External File Modification Watcher**:
  - Uses filesystem observation to monitor open files. If a document is updated externally (e.g., via Dropbox, OneDrive, Git, or another editor), a debounced prompt alerts you to reload the latest version.
- **Chromium Idle Background Auto-Save**:
  - Automatically saves named documents after 10 minutes of system inactivity. Runs completely in the background without any UI interruption.
  - For brand new, never-saved documents, a single non-stacking in-app modal prompts you to Save As when you return. No stacked system dialogs.
- **Non-Blocking Async Save**:
  - Saving large documents never freezes or stutters the UI. The entire save pipeline runs on a background IPC stream, leaving the canvas fully responsive throughout.
- **Power Management During Save/Export**:
  - The OS is prevented from sleeping or activating the screen saver while a save or export is in progress. Normal power behavior resumes immediately afterward.
- **Native Desktop Save Notification**:
  - A native OS notification toast appears each time a publication is successfully saved, confirming the save completed without needing to watch the status bar.
- **Backup Directory Relocation**:
  - Backup rotation files (`.bak`) are stored in a dedicated system directory (`AppData\Local\OpenPublisher\Backups`) rather than cluttering your working project folder. Old `.bak` files in working directories are automatically cleaned up on the next save.
- **Renderer Crash Recovery**:
  - Webview crashes are intercepted immediately; a replacement process launches automatically with the `--recovered` flag, presenting an interactive session restore modal and generating a diagnostic crash dump on the Desktop.
- **Taskbar Progress Indication**:
  - The Windows taskbar button shows a live green progress bar during saves and document loads, matching the status bar glow animation.

<a id="physical-measurement-units-and-dpi"></a>
## Physical Measurement Units and DPI

Open Publisher V5 introduces a mathematically authoritative physical unit and DPI engine designed for real-world print production.

### Unit Conversion System

The centralized `UnitConversionService` handles bidirectional conversion between all unit types at any DPI:

| Unit | Conversion |
|---|---|
| **Inches** | Pixels = Inches x DPI |
| **Centimeters** | Pixels = (cm / 2.54) x DPI |
| **Millimeters** | Pixels = (mm / 25.4) x DPI |
| **Pixels** | 1:1 direct mapping |

### DPI Presets

| DPI | Use Case |
|---|---|
| **72 DPI** | Draft and low-resolution screen |
| **96 DPI** | Standard web and CSS default |
| **140 DPI** | Medium resolution |
| **150 DPI** | Medium print quality |
| **300 DPI** | High-resolution professional print |
| **Custom** | Any numerical value |

### Physical Rulers

When a unit other than pixels is selected, the canvas rulers display tick marks in your chosen unit (cm, mm, or in). Ruler origin can be dragged from the intersection box to set a custom zero point.

### Print Precision at 300 DPI

- **Zero-spillage printing**: At 300 DPI, an A4 page measures 2480x3508px. The print engine calculates `@page` dimensions in correct physical inches (not raw pixels), ensuring the page prints on exactly one sheet of paper.
- **Blank page elimination**: Sub-pixel rounding protection prevents a 0.0022mm overflow from generating a blank trailing sheet.
- **DPI-aware margin presets**: The Normal (0.5"), Narrow (0.25"), Wide (1") ribbon margin buttons automatically scale margin pixels based on the document's active DPI.

### Format Persistence

Page format and DPI are stored in `.opub` files as explicit metadata. When you reopen a saved 300 DPI A4 document, it loads at 300 DPI A4 - not at "Custom" 96 DPI.

- **Developer HUD (`Ctrl+Shift+D`)**: Floating heads-up display showing live memory allocation graphs, RSS change rates, active DOM node counts, and frame rates.
- **Standalone Tearaway HUD**: Pop out the Developer HUD into an independent floating window (`hud.html`) across multi-monitor setups.
- **Bidirectional IPC Sniffer**: Real-time traffic monitor capturing and logging all communication passing between the host wrapper and webview.
- **Automated Crash Logging**: Automatically dumps hardware specifications, memory statistics, and process uptime to `OpenPublisher-Crash-Log.txt` on the Desktop if a crash occurs.
- **Safe Mode Actions**: Built-in actions to reboot the application in diagnostic Safe Mode directly from the HUD.
- **Open AppData Folder**: Quick access button to the application data directory for manual backup and log inspection.
- **Microsoft Agent (Clippy)**: Nostalgic interactive assistant featuring 41 authentic animations and 101 productivity tips.

<a id="document-security-and-privacy"></a>
## Document Security and Privacy

### Password Protection

Open Publisher encrypts documents using the **Web Crypto API (AES-GCM)**, an industry-standard algorithm implemented natively in the browser.

- Encrypted files save as binary blobs, completely unreadable without the correct password.
- A "Protected" badge appears in the top-right canvas area when a document is secured.
- To open a protected document: open the file, enter the password in the decryption prompt.

> **Warning:** There is no password recovery mechanism. If you lose the password, the document cannot be recovered. Always keep a backup of the unprotected source file.

### Document Inspector

**File > Info > Inspect Document** scans across all pages and checks:

| Category | What It Finds |
|---|---|
| Document Properties | Embedded author, company, subject, and keyword metadata |
| Off-Canvas Elements | Objects dragged partially or fully outside the page boundary |
| Empty Text Boxes | Text boxes containing only invisible characters (e.g., non-breaking spaces) |

Each category shows a colour-coded Found/Clean status with a one-click **Remove All** action to purge detected data.

<a id="the-opub-file-format"></a>
## The .opub File Format

Open Publisher's native format is `.opub`:

- **Double-click to open** on all supported platforms after installation.
- **Backwards compatible** with older versions of the application.
- Stores custom ruler origins, page notes, margin settings, master page overrides, theme preferences, DPI, physical unit, page format, and spread mode.
- Supports **AES-GCM encryption** for protected documents.

### Supported Import Formats

| Format | Import Behaviour |
|---|---|
| `.opub` / `.json` | Native format - full fidelity, restores entire working session |
| `.png`, `.jpg`, `.gif`, `.webp`, `.svg` | Placed directly onto the canvas with visual feedback |
| `.pub`, `.pubx` | Experimental legacy Microsoft Publisher import (layout fidelity varies) |
| `.xlsx`, `.xls` | Fully interactive table object via Import Wizard |
| `.doc`, `.docx` | Editable Text Mode or Flattened Image Mode (Safe Mode) |

**Word Document Import Modes:**
1. **Editable Text Mode** - Extracts all text, fonts, and colours into editable Open Publisher text boxes. Best for documents you want to continue editing.
2. **Flattened Image Mode (Safe Mode)** - Renders the document as a high-resolution background image, guaranteeing 100% layout accuracy. Recommended for complex forms, medical tables, or any document where pixel-perfect fidelity matters more than editability.
